# Wonder Island: Kids Learning Game (ages 5 to 7)

A colorful learning game where young children explore six adventures in one place. Every question is read aloud, so early readers can play on their own.

**Play it now:** https://alphazolo12200-tech.github.io/wonder-island-kids-learning/

## The six adventures

| Adventure | What children practise |
|---|---|
| Count It | Counting objects from 1 up to 15 |
| Letter Sounds | First letters of words, matching pictures to letters |
| Shapes and Colors | Naming shapes and colors, counting sides |
| Little Sums | Adding and taking away with pictures |
| Pattern Train | Finding what comes next in a pattern |
| Animal Friends | Animal sounds, homes and abilities |

## Made for young learners

- **Spoken questions.** A friendly voice reads every question, with a button to hear it again.
- **No failing.** A wrong answer wiggles gently, and after two tries the right answer glows.
- **Levels adjust automatically.** Each adventure has three levels that rise and fall to match the child.
- **Fresh questions every time.** Questions are generated, so they do not repeat like a fixed quiz.
- **Rewards.** Stars, confetti and 12 collectible stickers in a Sticker Book.
- **Private and safe.** No ads, no tracking, no accounts. Progress is saved only on the device.

## Tips for grown-ups

- Turn the sound on so the game can read the questions aloud.
- Ask your child to explain why they picked each answer. It builds understanding, not just speed.
- The voice comes from the device, so it may sound different on different phones and computers.

## Run it yourself

It is one HTML file. Download `index.html` and open it in any browser. No installation is needed.

## Tech

Plain HTML, CSS and JavaScript in a single file. It uses the browser's built-in speech synthesis for the voice and localStorage to save progress. No frameworks or libraries.
